# Backend

## Necessário

```
mkdir backend

cd backend

npm init -y

npm add express

npm add cors
```
## Rodar
```
cd backend

npm run dev
```

# Frontend

## Necessário
```
mkdir frontend

cd frontend

npx expo install react-dom react-native-web
```
```
npx create-expo-app . --template
```
### Rodar

```
cd frontend

npx expo start --clear
```
